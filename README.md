# 🎵 Brew Tune

## ■ 概要
短い制約の中で「誰でも簡単に作曲・投稿・再生できる」Webアプリ。  
鍵盤をクリックするだけで、4小節のメロディを作成し共有できます。

---

## ■ コンセプト
- 制約による創造性の最大化
- 音楽未経験者でも直感操作
- 作ってすぐ聴ける・共有できる

---

## ■ 機能一覧（MVP）

### 1. 作曲機能
- 鍵盤UIクリックで音入力
- 前から順に最大16音まで記録
- 入力状態をマス表示（16ステップ）

### 2. 音楽仕様（固定制約）
- 調：ハ長調（Cメジャー）
- 音域：C4〜C6（2オクターブ）
- 音価：4分音符のみ
- 拍子：4/4
- 小節：4小節（計16音）

### 3. テンポ切替
- 60 / 80 / 100 BPM の3段階
- 初期値：80 BPM

### 4. 再生機能
- 作成したメロディを即時再生
- テンポに応じた再生速度

### 5. 投稿機能（認証なし）
- ニックネーム入力で投稿
- 一覧表示・他ユーザーの再生可能
